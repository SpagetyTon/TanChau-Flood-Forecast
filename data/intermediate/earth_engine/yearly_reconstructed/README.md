# Yearly IMERG / ERA5-Land files

The files `imerg_2015.csv`…`imerg_2024.csv` and `era5_2015.csv`…`era5_2024.csv` in this folder are **not the original exported files**. They were reconstructed by splitting `data/raw/earth_engine/dataset_raw_2015_2024.csv.gz` (the table supplied by the team) by year.

Purpose: keep the yearly intermediate structure of the original workflow without implying that these are the original files.
