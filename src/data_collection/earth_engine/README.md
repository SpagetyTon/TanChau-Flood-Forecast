# Earth Engine collection code — reconstructed

The original Colab notebook was not recovered as a physical file. This folder therefore contains a **reconstructed** implementation based on the earlier SL | PTHT conversation history and the supplied `dataset_raw_2015_2024.csv.gz`.

Recovered fixed details include the collection IDs, three station coordinates, HydroBASINS Level 7 reverse-upstream trace, 15-step traversal, major-river filter `DIS_AV_CMS > 1000`, 50 km buffers, scale 11,132 m, UTC daily window, and the 19-column raw schema.

Use the reconstructed code as provenance/support code, not as proof that it is byte-for-byte identical to the lost Colab notebook.
